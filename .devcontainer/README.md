# Dev container config

This folder contains the configuration to work in a [dev container](https://containers.dev/).

See the https://github.com/guardian/devenv config tool for details.

## Getting started (IntelliJ)

1. open `user/devcontainer.json`
1. click the cube in the top left gutter
1. Create Dev container and Clone sources...
1. choose main when it loads, and click Build container.
1. wait for the Build log to show `Setup complete - you can now open the development container in your IDE`
1. Click the "trust and open" option and wait for the container's IntelliJ window to open
1. open a console and run `gh auth login` then follow through the process.
1. run `copilot` to start AI assisted coding.

## Developing

### `devenv.yaml`

The source-of-truth configuration for this project's dev container. Edit this file to add/remove devenv modules,
or any other config settings. Then run: 
```bash
devenv generate
``` 
to regenerate the shared `devcontainer.json` file.

### `shared/devcontainer.json`

A snapshot of the devcontainer configuration generated from `devenv.yaml`.

> [!IMPORTANT]
> Do not edit this file directly! Instead, edit `devenv.yaml` and then run `devenv generate`.
